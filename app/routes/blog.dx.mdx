Top engineering teams like Ramp and Stripe are building internal cloud agents -- massively parallelisable coding agents that have access to internal data sources, specialized skills, and can generate and deploy PRs.

These agents help engineers ship faster. But I think the bigger benefit is underrated: the process of building these platforms forces foundational developer experience (DX) improvements.

For example, internal cloud agents need:

- Reproducible environments
- Seamless connection to internal data sources like Notion, GitHub, DataDog, Linear
- Clear, consistent codebase patterns
- Composable skills
- Fast testing loop for self-verification
- Fast CI/CD
- Automated code review

All of these things are good for cloud agents... but they're also good for human engineers.

Generally, I've found what's good for humans is good for agents.

So yes, these internal cloud agents help teams ship more code. But they massively improve DX along the way. And that might lead to the bigger long term gains. As the leverage of each human engineer increases, DX matters more than ever.
